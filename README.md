## Project Overview

Catch Game is an interactive, game-based learning activity designed to make learning more engaging and enjoyable. Players control a basket to catch falling fruits while avoiding obstacles and aim to achieve the required passing score.

## Game Instructions

- Use the left and right arrow buttons to move the basket.
- Catch the falling fruits to earn points.
- Avoid the falling obstacles.
- Reach the target score of **80 points** to pass the game.

## Features

- Interactive gameplay
- Score tracking
- Passing score indicator
- Animated falling objects
- Basket movement controls
- Game-based learning experience
