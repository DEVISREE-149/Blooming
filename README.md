# Interactive E-Learning Projects – Articulate Storyline 360

## Project Overview

This repository showcases two interactive eLearning activities developed using Articulate Storyline 360. These projects demonstrate the use of game-based learning and interactive elements to create engaging and learner-friendly digital experiences.

## 1. Catch Game

### Description
Catch Game is an interactive, game-based activity where learners control a basket to catch falling fruits and achieve the required passing score.

### Instructions
- Use the left and right arrow buttons to move the basket.
- Catch the falling fruits to earn points.
- Avoid obstacles.
- Reach the target score of 80 points to pass the game.

### Features
- Interactive gameplay
- Animated falling objects
- Basket movement controls
- Real-time score tracking
- Target score indicator

## 2. Drag and Drop Interactivity

### Description
This project demonstrates a drag-and-drop interaction where learners drag objects and drop them into their corresponding target areas to complete the activity.

### Instructions
- Read the instructions displayed on the screen.
- Select and drag the available objects.
- Drop each object into its correct target area.
- Complete the activity by matching all objects correctly.
- Review the feedback provided.

### Features
- Interactive drag-and-drop functionality
- Customizable drag items and drop targets
- Learner interaction and participation
- Immediate feedback for learner responses
- Engaging activity-based learning

## Project Purpose

The purpose of these projects is to demonstrate the development of interactive eLearning content using Articulate Storyline 360. They showcase practical skills in creating engaging activities, interactive elements, game-based learning experiences, and learner feedback.

## How to View the Projects

1. Download or clone this repository.
2. Open the respective project folders.
3. Open the published `story.html` file in a web browser.
4. Interact with the activities to explore their functionality.
